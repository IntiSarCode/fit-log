FitLog 🏋️‍♂️

FitLog is a modern, responsive web application designed to help users discover, organize, and track their workout routines effortlessly. Built with Next.js and Tailwind CSS, it offers a seamless interface to explore exercises, calculate session metrics, and manage personalized fitness plans.

-------------------------------------------------------------------------------

🚀 Key Features

1.Interactive Exercise Library: Browse through a curated collection of lifts and workouts covering all major muscle groups.

2.Personalized Workout Planner: Easily add exercises to "Today's Plan" or save them for later with single-click context management.

3.Automated Metric Aggregation: Dynamically calculate total exercise count, estimated duration (in minutes), and burned calories (kcal).

4.Sorting & Filtering Options: Organize your active workout plan by calories burned or workout duration to optimize your routine.

5.Detailed Workout Views: Dedicated pages for individual workouts with exercise descriptions, equipment tags, and rating indicators.

6.Resilient API Integration: Built-in error handling and fallback mechanisms to ensure uninterrupted app usage even during network or rate-limit issues.

-----------------------------------------------------------------------------------------------------------

🛠️ Technologies Used

Framework: Next.js (App Router)

Library: React

Styling: Tailwind CSS

State Management: React Context API 

Deployment & Build: Vercel / Turbopack
